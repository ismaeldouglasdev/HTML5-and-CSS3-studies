## 📋 Sobre

Este repositório contém exercícios, desafios e projetos desenvolvidos durante o curso de **HTML5 & CSS3** ministrado pelo Professor **Gustavo Guanabara** no [Curso em Vídeo](https://www.cursoemvideo.com).

### 📂 Conteúdo

- 📝 **Exercícios práticos** — Aplicação dos conceitos aprendidos módulo a módulo
- 🧩 **Desafios** — Projetos propostos ao longo do curso
- 🌐 **Site-exemplo** — Projeto final do módulo

### 🧠 Tópicos Abordados

- ✅ Estruturação de páginas com HTML5 semântico
- ✅ Estilização com CSS3 (seletores, box model, flexbox, grid)
- ✅ Responsividade e media queries
- ✅ Boas práticas de acessibilidade

## 🚀 Como Usar

```bash
git clone https://github.com/ismaeldouglasdev/HTML5-and-CSS3-studies.git
```

Navegue pelas pastas e abra os arquivos `.html` no navegador.
